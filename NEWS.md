# unsaved 0.1.0

Track unsaved changes in Shiny forms and data-review apps.

- Mark changed fields and show a page-wide count badge.
- Guard tab navigation, tagged clicks and browser close or refresh.
- Save through a callback, with support for promises and edits during saving.
- Ask for a reason to pass to the app's audit code.
- Track server values and tables, with short cell change summaries.
- Restore supported inputs on discard and load a saved baseline explicitly.
- Support modules, several trackers and custom comparison rules.
- Customise dialog text, badge labels and marker styles.
